## Overview

**Groza 2.5.0** is a Russian-developed Android application (for Android 9.0 and later) designed to work seamlessly with the **“GLAZ”** system — a monitoring and data-exchange platform used by operators and engineers.  
The app offers real-time mapping, telemetry, and secure communication tools, providing full mobility and reliability in both online and offline environments.  

Groza 2.5.0 combines a modern interface with advanced functionality for field operations, situational awareness and network data management.

---

## Key Features

- 🌩 Integration with the **GLAZ** monitoring system for live data exchange.  
- 🗺 Real-time map visualization and object tracking.  
- ⚙️ Operator profile management and security control.  
- 🔒 Encrypted communication channels with VPN support.  
- 📡 Live telemetry feed and data logs.  
- 💾 Local storage and offline mode for fieldwork.  
- 🔄 Cloud synchronization and backup.  
- 🧭 Offline maps and location tracking without Internet access.

## Getting Started

1. Download **Groza 2.5.0** APK and install it on Android 9.0+.  
2. Allow required permissions (GPS, storage).  
3. Connect to **GLAZ** or work in offline mode.  
4. Set up an operator profile and synchronize initial data.  
5. Start monitoring, map visualization, or data exchange.
